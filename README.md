# 考研数学二 · 真题、习题册与答案解析（1987—2026）

收录 1987—2026 年考研数学二真题 Markdown 笔记及习题册。2000—2026 年真题含必要题图，答案与解析按年份独立成册。

## 文件结构

- 根目录：各年真题 MD，以及各年答案与解析 MD、PDF。
- `_习题册`：各年习题册 PDF、LaTeX 源文件与 `gen.py`。
- `_题图`：真题中的函数图、图形选项和几何示意图。

2000—2026 年习题册采用 240 mm × 200 mm 页面，纯白背景，无页眉页脚，一页一题。题号为 `YYYY.N`；原卷使用分节编号的年份，页首同时列出原卷题号。答案册先列答案，再按题号给出详细推导，关键公式独立成行。

## 重新生成习题册

需要 Python、TeX Live 的 XeLaTeX 和 Windows 中文字体。在仓库根目录执行：

```powershell
python _习题册/gen.py 2026

2000..2026 | ForEach-Object { python _习题册/gen.py $_ }
```

脚本读取根目录对应年份的真题 MD，输出 `_习题册/NNNN.tex` 与 `_习题册/NNNN.pdf`。题图随 Markdown 自动嵌入 PDF，编译时检查页数、缺字和内容溢出。

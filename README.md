# 考研数学二 · 真题与习题册（1987–2025）

本仓库收录 **1987–2025 年考研数学二真题**的 Markdown 笔记，并附一套由这些笔记自动生成的、适配平板手写的**习题册 PDF**（一页一题，便于刷题与作答）。

## 内容结构

```
Mathematics (II)/
├── 1987年考研数学二试题.md … 2025年考研数学二试题.md   每年真题笔记（共 39 套）
└── _习题册/                                         生成的习题册
    ├── 1987.pdf … 2025.pdf                          每套一年，一页一题
    ├── 1987.tex … 2025.tex                          对应 LaTeX 源
    └── gen.py                                       生成脚本
```

### 真题笔记（MD）
- 每年一个文件，含完整题干、选择题 `(A)(B)(C)(D)` 选项、填空题空位、解答题及小问。
- 公式用 LaTeX：行内 `$…$`、块级 `$$…$$`，含 `\dfrac`、`\begin{pmatrix}`、`\boldsymbol{}`、`\iint` 等。
- 以每年真题扫描页为准整理；个别含曲线/示意图的题目题干与条件已完整，但**图无法纯文本还原**，图所在位置留白（正文已注明）。

### 习题册（PDF）
- 页面 **240mm × 200mm**（横版，适配 3:2 平板）。
- **纯白背景**，无点阵 / 横线 / 网格，**无页眉页脚、页码**。
- **一页一题**，题号 `YYYY.N`（如 `2025.6`，即年份.当年试卷内题号）。
- 题干靠上，下方整片留白供手写作答。

## 重新生成习题册

需要已安装 **TeX Live**（含 `xelatex`）与中文字体。在仓库根目录执行：

```bash
# 生成指定年份
python _习题册/gen.py 2025

# 生成全部年份（1987–2025）
python _习题册/gen.py $(seq 1987 2025)
```

脚本读取根目录的 `NNNN年考研数学二试题.md`，输出到 `_习题册/NNNN.pdf`，每套一页一题、题号 `YYYY.N`。

## 说明

- 题目来源于历年考研数学二真题，仅作个人学习、整理与练习使用。
